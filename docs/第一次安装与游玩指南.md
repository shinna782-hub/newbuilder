# 《赛博修仙系统》第一次安装与游玩指南

欢迎来到《赛博修仙系统》。这不是传统安装包：你拿到的是一个完整的演示文件夹，游戏本体、法宝桥和任务沙盒都在里面。**请保留整个文件夹，不要只单独复制 `.app`。**

本指南适用于 macOS，Intel 芯片和 Apple 芯片的 Mac 都可以运行。

---

## 一、先选择你的体验方式

### 方式 A：只玩游戏

适合先看开场、地图、种田和器灵战斗。不需要安装 Godot、Node.js 或 ZCode。

1. 打开 `赛博修仙-演示包` 文件夹。
2. 右键点击 `赛博修仙系统.app`，选择「打开」。
3. macOS 第一次询问时，再点击一次「打开」。
4. 以后可以直接双击游戏。

只打开 `.app` 时，游戏主体可以正常游玩，但“去修炼”不会把任务派发到 ZCode。

### 方式 B：体验完整的“法宝桥”玩法

这种方式可以把游戏任务变成 ZCode 里的真实会话。首次使用前需要：

- 安装并登录 **ZCode 桌面端**；
- 安装 **Node.js 22.5 或更高版本**；
- 保持电脑联网，并确保 ZCode 能正常新建会话。

准备好后：

1. 右键点击 `启动.command`，选择「打开」。
2. 终端会依次启动法宝桥、ZCode 和游戏。
3. **不要关闭这个终端窗口**，关闭后法宝桥会断开。
4. 在 ZCode 中选择「添加项目 / 打开文件夹」。
5. 选中演示包里的 `演示沙盒` 文件夹。
6. 确认 ZCode 左侧项目列表出现「演示沙盒」，再回到游戏点击「去修炼」。

> `启动.command` 会尝试自动打开沙盒，但第一次安装时仍建议手动添加一次。否则任务可能已经在后台运行，会话却不会显示在 ZCode 界面里。

---

## 二、第一次进入游戏

1. 首页点击「开始游戏」。
2. 完整看一遍开场说明和三段 PV，点击画面继续。
3. 进入万象宗后，可以从顶部导航打开「道身」「地图」「任务」。
4. 先去「地图 → 宗门大殿」领取历练任务。
5. 再前往青芜原据点，与师兄交易种子、爆破符和灵液。
6. 进入青芜原后，可用数字键切换工具，也可点击底部工具格：
   - 爆破符：清理荒地和杂石；
   - 青芒草种子：在空地种植；
   - 灵液：立即催熟已种下的青芒草；
   - 器灵：遇到灵兽时进入两回合战斗。
7. 第一次收割青芒草后，底部会出现“青芒草”库存格。

想重新观看新手流程，可以在游戏首页点击「重置游戏」。

## 三、第一次启动被 macOS 拦截怎么办

游戏和启动脚本没有进行 Apple 商店签名，所以新电脑第一次打开时可能提示“无法验证开发者”。

优先这样处理：

1. 不要直接双击；对 `赛博修仙系统.app` 或 `启动.command` 点击右键。
2. 选择「打开」。
3. 在新的确认窗口里再次选择「打开」。

如果仍被阻止：打开「系统设置 → 隐私与安全性」，在安全提示旁点击「仍要打开」。只需要放行一次。

## 四、常见问题

### 开场黑屏，提示“帧序列为空”

当前演示包已经包含完整的三段帧序列。请确认你复制的是**整个最新演示包**，不要把旧 `.app` 与新文件夹混用。如果仍出现该提示，请重新复制完整文件夹。

### 首页显示“法宝桥：未连接”

- 确认是通过 `启动.command` 打开的，而不是只打开 `.app`；
- 确认终端窗口仍在运行，并显示“法宝桥已通”；
- 确认 Node.js 版本不低于 22.5；
- 如果电脑开着代理或 VPN，先暂时关闭后重新运行启动脚本。

### 点击“去修炼”，ZCode 没出现会话

1. 在 ZCode 里手动选择「添加项目 / 打开文件夹」。
2. 选择演示包里的 `演示沙盒`。
3. 若左侧仍没有项目，退出并重新打开一次 ZCode。
4. 再回游戏重新点击“去修炼”；会话出现可能需要十几秒。

### 没有声音

检查系统音量、当前输出设备和静音状态。游戏开场旁白与背景音乐会同时使用系统音频输出。

### 想完全重新开始

回到游戏首页点击「重置游戏」。这会重置游戏内进度，不会删除 ZCode 里的历史会话。

---

## 五、复制到另一台电脑时

- 复制整个 `赛博修仙-演示包` 文件夹；
- 不要拆开 `.app`、`法宝桥`、`演示沙盒` 和 `启动.command`；
- 完整玩法需要在新电脑上重新登录 ZCode，并重新添加那台电脑上的 `演示沙盒`；
- 上台或正式试玩前，先完整看完三段开场 PV，再真实派发一条任务确认链路。

如果你只是想开始玩：**右键打开 `赛博修仙系统.app` 即可。**
